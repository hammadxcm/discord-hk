# Claude Memory - Discord HK Project

This file contains important context and commands for Claude to remember when working on this project.

## Project Overview
This is a comprehensive Discord server setup project that combines:
1. **Server Configuration Guide** - Best practices for Discord server setup
2. **Bot Integration Guide** - Setup instructions for popular Discord bots
3. **Custom TypeScript Bot** - Additional features not covered by existing bots

## Key Commands
- `npm run dev` - Start development server
- `npm run build` - Build TypeScript to JavaScript  
- `npm start` - Start production server
- `npm run lint` - Run ESLint
- `npm run typecheck` - Type checking

## Important Files
- `docs/server-setup-guide.md` - Complete server configuration guide
- `docs/bot-integrations.md` - External bot setup instructions
- `docs/setup-instructions.md` - Step-by-step setup guide
- `docs/legal/` - Terms of service, rules, and guidelines
- `src/` - Custom bot source code

## Bot Features
- Advanced moderation system
- Custom leveling system (complementing MEE6)
- Economy system with virtual currency
- Welcome/goodbye messages
- Reaction roles
- Ticket system integration
- Analytics and logging

## Database Models
- `User` - Individual user data and statistics
- `Guild` - Server configuration and settings

## External Bot Integrations
- **MEE6** - Primary leveling and basic moderation
- **Carl-bot** - Advanced automod and reaction roles
- **Dyno** - Backup moderation and server stats
- **Jockie Music** - Music streaming
- **GiveawayBot** - Giveaway management
- **TicketTool** - Support ticket system

## Development Notes
- Uses Discord.js v14 with latest dependencies
- MongoDB for data persistence
- TypeScript for type safety
- Comprehensive error handling and logging
- Modular command and event system
